## How I think about engineering

```text
Understand the decision.
Remove the friction.
Make the behavior predictable.
Then write the code.
```

- A feature is not finished when it works; it is finished when people understand it.
- Simple architecture is a competitive advantage, especially when a team grows.
- Frontend quality includes accessibility, performance, state design, and failure states.
- Learning backend and systems programming makes me a better frontend engineer.
- The best side projects begin with a real inconvenience, not a list of trendy technologies.
